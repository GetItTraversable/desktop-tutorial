AIでアプリを作る人のための

UIの名前クイズ

「あの、画面の端からにゅっと出るやつ」を「Drawer」と言えるようになると、AIへの指示が一気に正確になります。実際に動くUIを見ながら、名前を覚えましょう。

UI用語集（43語）

クイズに出てくるUIの名前・説明・名前の由来の一覧です。レベル名を押すと開きます。

初級（16語）

まずはここから。どのアプリにもある基本の部品
Button ボタン
押すと処理を実行する部品。保存・送信など、操作のきっかけになる。
名前の由来服のボタンや、機械の「押しボタン」から。押すと何かが起きる、あのボタンをそのまま画面に持ってきた。
Text field テキストフィールド
1行の文字を入力する枠。上のラベルや、中に薄く表示する例文（プレースホルダー）と組み合わせて使う。
名前の由来field は書類の「記入欄」のこと。申込書の「お名前：＿＿＿」の空欄が、画面の中に引っ越してきた。
Checkbox チェックボックス
四角い箱にチェックを入れる部品。複数の選択肢を同時に選べる。
名前の由来紙のアンケートの、✓を書き込む四角い箱（box）から。選びたいものに印をつける感覚そのまま。
Radio button ラジオボタン
丸い印のついた選択肢。グループの中から1つだけを選ぶ。
名前の由来昔のカーラジオの選局ボタンが由来。1つ押し込むと、前に押していたボタンがポンと戻るので、同時に1つしか選べない。
Toggle switch トグルスイッチ
つまみを左右に動かしてオン・オフを切り替えるスイッチ。押した瞬間に設定が反映されるのが普通。
名前の由来toggle は「パチッと切り替える」の意味。部屋の照明についている、レバーを倒すスイッチと同じ仕組み。
Dropdown (Select) ドロップダウン（セレクト）
押すと選択肢の一覧が開き、その中から1つを選ぶ部品。選択肢が多くても場所を取らない。
名前の由来押すと一覧が下に「落ちてくる（drop down）」ように開くから。Select は「選ぶ」。
Navigation bar ナビゲーションバー
画面の上部に横に並ぶ、サイトの主なページへのリンク。ロゴもここに置くことが多い。
名前の由来navigation は船の「航海術」。サイトという海を迷わず進むための、羅針盤みたいな帯。
Hamburger menu ハンバーガーメニュー
三本線のアイコン。押すと隠れていたメニューが出てくる。スマホのような狭い画面でよく使う。
名前の由来三本線が、パン・ハンバーグ・パンを重ねたハンバーガーに見えるから。1981年のパソコン「Xerox Star」で生まれたアイコンと言われる。
Card カード
画像・タイトル・短い説明などを1つの枠にまとめた部品。一覧に並べて使うことが多い。
名前の由来トランプや名刺、図書館の目録カードのように、1枚に情報をぎゅっとまとめるから。
Modal dialog モーダル（ダイアログ）
画面の中央に開く小窓。後ろの画面は暗くなり、閉じるまで他の操作ができない。
名前の由来「モード（mode）」から。開いている間、アプリは「あなたの返事待ちモード」になり、他のことは一切受け付けない。
Toast トースト
画面の端に一時的に出て、数秒で自動的に消える短い通知。作業の邪魔をしない。
名前の由来トースターからパンがポンッと飛び出すように、画面の下からひょこっと現れるから。焼き上がったらすぐ食べられるように、すぐ消える。
Tabs タブ
見出しを横に並べ、押すとその下の内容が切り替わる部品。1つの画面の中で情報を整理する。
名前の由来ノートやファイルの端についている「見出しの耳（インデックスタブ）」から。耳をつまんでページを開く感覚。
Tooltip ツールチップ
マウスを乗せたり、キーボードで選んだりしたときに出る小さな補足の吹き出し。中に押せるものは入れない。
名前の由来tool（道具＝ボタン）の tip（ちょっとしたコツ・ヒント）。道具の使い方を、横からこっそり耳打ちしてくれる。
Badge バッジ
アイコンなどの角に付く小さな印。未読の数や「NEW」などの状態を知らせる。
名前の由来制服やかばんにつける「バッジ」から。小さな印1つで「新着あり」などの状態を知らせる。
Avatar アバター
ユーザーを表す小さな丸い画像。画像がないときは名前の頭文字を表示することが多い。
名前の由来サンスクリット語で、神様が地上に現れるときの「化身」のこと。ネットの世界でのあなたの分身。
Spinner スピナー
くるくる回る印。処理中・読み込み中であることを伝える。あとどれくらい待つかは分からない。
名前の由来くるくる回る（spin）から。コマのように回り続けて「今がんばってます」と伝える。

中級（15語）

使いやすさに差が出る、画面の構成と状態の部品
Drawer ドロワー
画面の端から引き出しのように滑り出てくるパネル。メニューや詳しい情報を表示する。
名前の由来机の「引き出し」。必要なときだけスッと引き出して、使い終わったらしまう。
Popover ポップオーバー
ボタンなどを押すと、そのすぐ近くに開く小さなパネル。中にボタンや入力欄など、操作できるものを置ける。
名前の由来ボタンの上に「ぽんと（pop）かぶさる（over）」ように出てくるから。
Accordion アコーディオン
見出しを押すと、その下の内容が開いたり閉じたりする部品。「よくある質問」でよく使う。
名前の由来楽器のアコーディオン。蛇腹が伸び縮みするように、内容が開いたり閉じたりする。
Breadcrumb パンくずリスト
「ホーム › カテゴリ › 商品」のように、今いるページまでの道のりを示すリンクの列。
名前の由来童話『ヘンゼルとグレーテル』で、帰り道の目印に落としていったパンくずから。来た道をたどって戻れる。
Skeleton screen スケルトンスクリーン
読み込み中に、実際の内容と同じ形の灰色のブロックを仮に表示するもの。待ち時間を短く感じさせる。
名前の由来「骸骨・骨組み」のこと。中身（肉）がつく前に、骨組みだけを先に見せておく。
Empty state エンプティステート
データがまだ1件もないときに表示する画面。何をすればいいかを案内し、最初の操作を促す。
名前の由来そのまま「空っぽの状態」。何もない画面を、次にすることの案内板に変える。
Pagination ページネーション
長い一覧をページに分け、「‹ 1 2 3 … ›」のような番号で移動できるようにする部品。
名前の由来本にページ番号を振ること（paginate）から。長い一覧を、本のようにページに分ける。
Progress bar プログレスバー
処理の進み具合を、横長の棒の伸び具合で示す部品。あとどれくらいで終わるかが分かる。
名前の由来進み具合（progress）を示す棒（bar）。ゲームの読み込み画面でおなじみ。
Stepper ステッパー
「1 入力 → 2 確認 → 3 完了」のように、手続きの中で今どの段階にいるかを示す部品。
名前の由来階段の段（step）から。1段ずつ上るように、手続きを順番に進んでいく。
Chip (Tag) チップ（タグ）
短い言葉を角の丸い小さな枠で囲んだ部品。絞り込みの条件やタグを表し、×で外せることも多い。
名前の由来ポーカーのチップのような、小さくて丸っこい札の見た目から。Tag は荷物につける「荷札」のこと。
Alert banner アラートバナー
画面の上部や内容の上に帯状に表示するお知らせ。自動では消えず、ユーザーが閉じるまで残ることが多い。
名前の由来お店の横断幕や、中世の旗（banner）から。帯状に大きく掲げて、目立たせる。
Slider スライダー
つまみを左右に動かして、決まった範囲の中から数値を選ぶ部品。音量や価格帯の指定に使う。
名前の由来つまみを滑らせる（slide）から。音響機材の音量つまみ（フェーダー）と同じ動き。
Sidebar サイドバー
画面の左右どちらかに常に表示されている縦長の領域。管理画面のメニューなどに使う。
名前の由来新聞や雑誌で、本文の横に置かれる囲み記事を「サイドバー」と呼んだことから。
Carousel カルーセル
複数の画像やカードを横に並べ、矢印やスワイプで1枚ずつ切り替えて見せる部品。
名前の由来遊園地のメリーゴーラウンドのこと（英語で carousel）。ぐるぐる回って、次々に新しいものが目の前に来る。
Floating action button (FAB) フローティングアクションボタン
画面の右下などに浮かんだまま固定される丸いボタン。その画面で一番よく使う操作を置く。
名前の由来画面の上に「浮かんでいる（floating）」ボタンだから。スクロールしても、ぷかぷかとその場に浮いたまま。

上級（12語）

大きなアプリや業務ツールで使う、一歩進んだ部品
Combobox コンボボックス
文字を入力すると候補が絞り込まれ、その一覧から選べる入力欄。入力欄とDropdownを合わせたもの。
名前の由来combination（組み合わせ）の box。入力欄と選択肢の一覧を「合体」させた箱。
Segmented control セグメンテッドコントロール
2〜5個ほどの選択肢を一続きにつなげたボタン。1つを選ぶと、同じ内容の表示方法がすぐ切り替わる。
名前の由来1本のボタンを、いくつかの区切り（segment）に分けたもの。みかんの房も英語では segment。
Command palette コマンドパレット
キー操作（⌘K など）で呼び出す検索窓。機能やページの名前を打つだけで、すぐに実行・移動できる。
名前の由来画家のパレットに絵の具が並ぶように、命令（command）がずらりと並ぶから。好きなものをさっと選べる。
Infinite scroll 無限スクロール
一覧の一番下まで来ると、自動で続きを読み込んで足していく仕組み。SNSのタイムラインなどで使う。
名前の由来そのまま「終わりのないスクロール」。底が見えない井戸のように、下へ下へと続いていく。
Bottom sheet ボトムシート
スマホの画面の下からせり上がってくるパネル。追加の選択肢や詳しい情報を表示する。
名前の由来画面の底（bottom）から、紙（sheet）が1枚スッとせり上がってくるイメージ。
Context menu コンテキストメニュー
右クリックや長押しをした場所に出る操作の一覧。押した対象に合わせた操作（名前の変更・削除など）を出す。
名前の由来context は「文脈・その場の状況」。右クリックした物に合わせて、中身が変わる気の利くメニュー。
Data table データテーブル
行と列でたくさんのデータを並べる表。並べ替え・絞り込み・行の選択などの機能を持つことが多い。
名前の由来データを並べた「表（table）」。table は元々、物を広げる平らな板のこと。そこに数字を広げて見る。
Split button スプリットボタン
よく使う操作のボタンと、▼で別の操作を選べる部分が1つにつながったボタン。
名前の由来1つのボタンを2つに「割った（split）」から。左半分は即実行、右半分は「ほかにもあるよ」。
Tree view ツリービュー
フォルダのように階層になった項目を、▶で開いたり閉じたりしながら表示する部品。
名前の由来幹から枝が分かれる木（tree）の形。画面では、根っこを上にした逆さまの木になっている。
Sticky header スティッキーヘッダー
スクロールしても画面の上端に貼り付いたまま残るヘッダー。どこまで読んでもメニューを使える。
名前の由来付箋（sticky note）のように、画面の上にペタッと貼りついて離れないから。
Inline validation インラインバリデーション
入力欄ごとに、入力した直後にその場で内容が正しいかを確かめ、欄のすぐ下にエラーやOKを表示する仕組み。
名前の由来in line は「その行の中で」、validation は「正しいかの確認」。入力したその場で、すぐに答え合わせをしてくれる。
Mega menu メガメニュー
ナビゲーションの項目にカーソルを乗せると開く大きなメニュー。たくさんのリンクを列に分けて一度に見せる。
名前の由来mega は「巨大な」。ふつうのメニューの何倍も大きく広がるから。
